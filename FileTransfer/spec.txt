# SSH 파일 전송 클라이언트 설계서

## 1. 기본 요구사항

### 기술 스택
- 프로토콜: SSH/SFTP
- SSH 라이브러리: paramiko
- UI: PySide6
- 파이썬: 3.8+

### 핵심 기능
- SSH 서버 연결 (패스워드/키 인증)
- 로컬-원격 파일 업로드/다운로드
- 디렉토리 탐색 및 관리
- 드래그 앤 드롭 지원
- 전송 진행률 표시

## 2. 보안
- SSH 키 인증 (RSA, Ed25519)
- 패스워드 인증
- SSH 프로토콜 보안
- 연결 타임아웃

## 3. 에러 처리
- 연결 끊김 시 재연결
- 전송 실패 시 재시도
- 권한 오류 알림

## 4. UI 구성
- 좌측: 로컬 파일
- 우측: 원격 파일
- 하단: 전송 상태
